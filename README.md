# TZJBox

本地图片排序工具。用来处理下载器或二次重命名留下的伪前缀，例如 `001_10.jpg` 应按 `10` 而不是 `001` 排序。

## 运行

需要 .NET 10 SDK。

```bash
dotnet run --project src/TZJBox.App
```

也可以直接打开一个文件夹：

```bash
dotnet run --project src/TZJBox.App -- "D:\Pictures\某图包"
```

## 排序

文件名会先被拆成数字块，再按当前模式抽出排序键。真正参与排序的数字会在列表里用琥珀色标出。

- **智能识别**：看整个文件夹。`page`、`ep`、`第X话/页` 优先；全员补零的前缀会让位给后面没补零的序号。
- **末尾序号优先**：去掉分辨率、日期和 10 位以上长编号后，取最后一个数字。
- **前缀剥离**：跳过前几个分隔符，再对剩余文字做自然排序。
- **正则捕获**：按完整文件名匹配，使用第一个括号里的数字。
- **拍摄时间**：优先 EXIF 的 `DateTimeOriginal`，没有则用修改时间。不使用创建时间。
- **自然排序**：从左到右，数字按数值比较。

如果某一段数字在全文件夹里完全一样，会当成图包编号忽略。分辨率（如 `1920x1080`）和 `20261013`、`2026-10-13` 这类日期默认剔除。

## 规范化重命名

确认预览里的新名字后，工具会先改成临时文件，再改成最终名字，避免 `001_10.jpg` 和已有的 `010.jpg` 互相覆盖。有明确序号时保留该数字并补零（`10` → `010.jpg`）；没有单一序号时按当前顺序编成 `001`、`002`。
